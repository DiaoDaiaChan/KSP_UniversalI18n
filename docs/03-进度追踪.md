**③ 为什么可以排除插件**

- 当时部署的二进制是 **26,112 B 的旧版**（现已停放为 `UI18n.Runtime.dll.old-9c712ab1`，sha256 `9C712AB13ED5E13E…`），而崩溃发生在「before main menu」，插件连托管代码都没进到。
